# CueTwin

CueTwin is a Windows desktop video editor with a local AI assistant and local voice cloning, made by [Athian Games](https://athiangames.com).

**Free during the public beta.**

- Website: https://cuetwin.netlify.app
- Privacy: https://cuetwin.netlify.app/privacy/

## Download

Windows 10/11 (64-bit) builds will be published on the [Releases](https://github.com/ar3emis/cuetwin/releases) page once the first public beta is out. None is available yet.

## Reporting bugs

- **From the app:** use the built-in bug reporter. Reports appear here as public issues, labelled `in-app`.
- **On GitHub:** [open an issue](https://github.com/ar3emis/cuetwin/issues/new). Include the app version, your Windows version, CPU, GPU and RAM, numbered steps to reproduce, and what you expected to happen.

Issues are public. **Never post licence keys, API keys, or private footage or recordings.**
